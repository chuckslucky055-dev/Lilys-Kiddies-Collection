# Lilys Kiddies Collection

Multi-page children's essentials storefront demo for ages 0–10.

## Pages and features
- Home, Shop, Baby Essentials, School Kits, About and Contact pages
- Product imagery and WhatsApp product enquiries
- Responsive layout for mobile and desktop

## Run locally
```bash
npm install
npm run dev
```

Live demo: https://lilys-kiddies-collection-6cm075.v2.appdeploy.ai/

This is a demo storefront. Confirm stock, product details and current prices directly with the store.
